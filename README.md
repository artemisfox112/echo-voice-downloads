# Echo Voice — загрузки для Windows

Это **официальный публичный репозиторий с установщиками Echo Voice**, опубликованный автором проекта. Здесь размещаются только готовые сборки приложения, контрольные суммы и инструкции. Основной репозиторий с кодом сервиса остаётся отдельным и приватным.

**Сайт:** https://echo-voice-production.up.railway.app/

**Актуальный Windows-релиз: 1.6.4.** Номер версии также показывается рядом со скачиванием на сайте. После следующей публикации обновляйте эту строку вместе с номером на сайте.

**Что изменилось в 1.6.4:** в правой панели под индикатором микрофона появился необязательный шумодав RNNoise для фонового шума (включая вентиляторы). Обработка идёт на компьютере, не на сервере; при сбое Echo возвращается к стандартному WebRTC. Улучшено ожидание закрытия приложения во встроенном обновляторе и добавлены локальные записи ошибок. Шумодав по умолчанию выключен. Интерфейсные улучшения 1.6.3 сохраняются.

## Скачать приложение

Перейдите в [последний релиз](https://github.com/artemisfox112/echo-voice-downloads/releases/latest) и выберите один из файлов:

- **EchoVoice-Setup.exe** — установка для Windows 10/11 x64 с выбором папки; в обычную пользовательскую папку права администратора не нужны.
- **EchoVoice-Windows-Portable.zip** — портативная версия. Распакуйте архив целиком и запустите `EchoVoice.exe`.
- **SHA256SUMS.txt** — контрольные суммы опубликованных файлов для проверки целостности.

Для Windows-клиента требуется **Microsoft Edge WebView2 Runtime**. Echo Voice позволяет создавать голосовые комнаты без регистрации, общаться в чате и сворачивать приложение в системный трей.

**Как проверить обновление:** начиная с версии 1.6.3, номер установленной версии отображается в правой верхней части Echo Voice (в старых выпусках — внизу окна). Приложение ненавязчиво проверяет новый стабильный релиз GitHub при запуске и примерно раз в 12 часов; при наличии обновления появляется ссылка на этот репозиторий. Ничего не скачивается и не устанавливается автоматически. Также версию можно посмотреть в Параметры Windows → Приложения → Echo Voice. Начиная с 1.6.2, при нажатии «Обновить» появится подтверждение, после которого Echo автоматически скачает, проверит и установит следующую версию. Старые версии и портативные сборки обновляются вручную: закройте Echo через пункт «Выйти из Echo» в трее и установите актуальный выпуск; локальные настройки WebView2 сохраняются.

> **Внимание:** установщик пока **не имеет цифровой подписи издателя**. Windows SmartScreen может показать предупреждение о неизвестном приложении. Проверяйте адрес официального репозитория и SHA-256 файла перед запуском. Предупреждение само по себе не доказывает ни безопасность, ни вредоносность файла.

### Проверка скачанного файла

В PowerShell:

```powershell
Get-FileHash .\EchoVoice-Setup.exe -Algorithm SHA256
```

Сравните полученное значение с записью в `SHA256SUMS.txt` соответствующего релиза.
