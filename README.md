# Echo Voice — загрузки для Windows

Это **официальный публичный репозиторий с установщиками Echo Voice**, опубликованный автором проекта. Здесь размещаются только готовые сборки приложения, контрольные суммы и инструкции. Основной репозиторий с кодом сервиса остаётся отдельным и приватным.

**Сайт:** https://echo-voice-production.up.railway.app/

**Актуальный Windows-релиз: 1.6.6.** Номер версии также показывается рядом со скачиванием на сайте.

**Что изменилось в 1.6.6:** повышена надёжность WebRTC при одновременном подключении, восстановлении сети и обработке ICE-кандидатов. Улучшены безопасность автообновления, очистка временных файлов, восстановление WebView2 и диагностика соединения. В 1.6.5 были исправлены ошибки управления микрофоном, push-to-talk, RNNoise, WebSocket и отката установщика. Все функции и оформление Echo сохранены; новых платных сервисов нет.

## Скачать приложение

Перейдите в [последний релиз](https://github.com/artemisfox112/echo-voice-downloads/releases/latest) и выберите один из файлов:

- **EchoVoice-Setup.exe** — установка для Windows 10/11 x64 с выбором папки; в обычную пользовательскую папку права администратора не нужны.
- **EchoVoice-Windows-Portable.zip** — портативная версия. Распакуйте архив целиком и запустите `EchoVoice.exe`.
- **SHA256SUMS.txt** — контрольные суммы опубликованных файлов для проверки целостности.
- **release-manifest.json** (начиная с 1.6.6) — сведения о версии, хешах сборок и исходном коммите, необходимые новому обновлятору.

Для Windows-клиента требуется **Microsoft Edge WebView2 Runtime**. Echo Voice позволяет создавать голосовые комнаты без регистрации, общаться в чате и сворачивать приложение в системный трей.

**Как проверить обновление:** начиная с версии 1.6.3, номер установленной версии отображается в правой верхней части Echo Voice (в старых выпусках — внизу окна). Приложение ненавязчиво проверяет новый стабильный релиз GitHub при запуске и примерно раз в 12 часов. В установленном Echo 1.6.2 и новее кнопка «Обновить» сначала спрашивает согласие, предупреждает о перезапуске и возможном отключении от комнаты; только после подтверждения приложение скачивает, проверяет и устанавливает новую версию. **Без подтверждения обновление не устанавливается.** Портативные сборки и установленные версии до 1.6.2 обновляются вручную. Если встроенное обновление не удалось, скачайте установщик вручную, закройте Echo через «Выйти из Echo» в трее и установите новую версию; профиль WebView2 должен сохраниться. Версию также можно посмотреть в Параметры Windows → Приложения → Echo Voice.

> **Внимание:** установщик пока **не имеет цифровой подписи издателя**. Windows SmartScreen может показать предупреждение о неизвестном приложении. Проверяйте адрес официального репозитория и SHA-256 файла перед запуском. Предупреждение само по себе не доказывает ни безопасность, ни вредоносность файла.

### Проверка скачанного файла

В PowerShell:

```powershell
Get-FileHash .\EchoVoice-Setup.exe -Algorithm SHA256
```

Сравните полученное значение с записью в `SHA256SUMS.txt` соответствующего релиза.
